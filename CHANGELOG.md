# Changelog

## 1.0

First public release.

- Construct maps drawn as editable SVG from an Excel workbook
- 55 part types across 22 glyph shapes, each declaring whether its width
  carries information
- 17 themes, 10 styles, 13 palettes, chosen by name in the spreadsheet
- Labels inside, above or below the glyph, printed once or on every use
- Colour assignment deterministic in the part label and checked for
  perceptual distance, so a gene keeps its colour and never collides
- Sanity check reporting illegible label sizes, overflowing glyphs,
  exhausted palettes and colour-blind collisions
- Gallery of worked examples in `examples/`, regenerated by
  `examples/make_gallery.py` so it cannot drift from the code
- 123 tests, run on Python 3.8 through 3.13

### Fixed before release

- An outside or below label on the first or last part of a construct was
  centred on its glyph and so hung past the edge of the canvas, which cut
  the name off. The canvas now includes label ink in its bounds.
